Đặt vào thư mục này 3 file font:

  Isometra-Regular.ttf   (đã có sẵn)  -> chữ "E-WALLET"
  Roboto-Regular.ttf     (cần tải)    -> chữ thường
  Roboto-Medium.ttf      (cần tải)    -> tiêu đề, nút, nhãn

Tải Roboto tại: https://fonts.google.com/specimen/Roboto
(nút "Get font" -> "Download all" -> lấy 2 file trong thư mục static/)

Nếu thiếu font, ứng dụng vẫn chạy bình thường bằng font dự phòng của hệ thống.
